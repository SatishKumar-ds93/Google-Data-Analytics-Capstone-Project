## HOW TO INSTALL R STUDIO

To install RStudio, you must first install the R programming language, as RStudio is an interface (IDE) that requires R to function.


### Step 1: Install R (The Engine)

**1.	Visit CRAN: Go to the [Comprehensive R Archive Network (CRAN) website](https://cran.r-project.org/).**

**2.	Select OS: Choose the link for your operating system (Windows, macOS, or Linux).**

- 1.	Windows: Click "base," then click the link to download the latest version 
(e.g., "Download R 4.x.x for Windows").

- 2.	macOS: Download the latest .pkg file that matches your version of macOS.

**3.	Run Installer: Open the downloaded file and follow the setup wizard.**

- 1.	For Windows, you can typically accept all default settings.

- 2.	For macOS, follow the standard installation prompts to add R to your applications. 



### Step 2: Install RStudio (The Interface)

1.	Visit Posit: Go to the [Posit Download page](https://docs.posit.co/ide/user/#rstudio-ide-oss-downloads) (formerly RStudio).

2.	Download Desktop: Scroll to "RStudio Desktop" and click the Download RStudio button.

3.	Run Installer:

- 1.	**Windows**: Open the .exe file and click "Next" until finished.

- 2.	**macOS**: Open the .dmg file and drag the RStudio icon into your Applications folder.

- 3.	**Linux**: Download the appropriate package (.deb for Ubuntu/Debian or .rpm for Fedora/Red Hat) and install it using your package manager.



### Step 3: Launch and Verify

1.	Open RStudio: Find RStudio in your applications menu and launch it.

2.	Verify Connection: Look at the "Console" pane (usually on the left). It should display the version of R you just installed.

3.	Run a Test: Type 2 + 2 in the console and press Enter. If it returns [1] 4, your installation is successful.
